Tabvora Features

Explore the features built into Tabvora, with a local-first architecture designed for privacy, productivity, and control.

Core Architecture

Workspace Shortcut Folders

Organize saved shortcuts into custom, color-coded workspace folders (e.g., Development, Research, Personal) on your new-tab dashboard. Switch between them instantly with hotkeys.

Wellbeing

Digital Wellbeing (Optional, Default OFF)

Receive gentle, local wellness reminders (Eye, Stretch, Walk, and Long Break) to reduce eye strain and encourage screen breaks. Operates strictly using session-based timers that automatically reset when Chrome closes.

Productivity

Website & Browser Usage Limits

Set max daily usage thresholds for specific websites or set a global Chrome usage cap. Native glassmorphism popups automatically alert you in real-time — even while watching videos — without any remote logging.

Dashboard

Browser Usage Dashboard Card

An optional dashboard widget that displays real-time progress toward your daily Chrome browser limit. Easily toggle it on or off anytime via Appearance Settings.

Local Statistics

Website Usage Statistics (Optional, Default OFF)

An optional, local-only view of domain visit frequency, duration, and calendar breakdowns. All calculations remain strictly in local storage and can be cleared instantly.

Data Recovery

Local Draft Recovery (Optional, Default OFF)

Temporarily saves unsaved text-field input across tabs to prevent data loss from accidental tab closes. Snapshots stay in local IndexedDB, and password or payment fields are strictly excluded.

Performance

Virtual Scrolling Grid

Only the shortcuts currently in view are rendered, ensuring the dashboard stays ultra-fast and responsive even with hundreds of saved shortcuts.

Data Control

Local Backup & Export

Export and import your shortcuts, workspace folders, and settings as a standardized local JSON backup file — no user account, server, or cloud sync required.

Navigation

Deep Shortcut Search

Instantly search your saved shortcuts by title, URL, domain, or notes, with configurable search scope and keyboard-first navigation (Ctrl+K).
