Product Roadmap

Our transparent release timeline. Built with zero tracking, local-first storage, and strict Google Developer Policy compliance.

Completed

v2.0.0 – Digital Wellbeing & Usage Limits

August 2026

Introduced session-based Digital Wellbeing break reminders, website and global daily browsing limits, and browser usage tracking cards.

  • ✓ Session-only Digital Wellbeing break reminders (Eye, Stretch, Walk)
  • ✓ Website-level and global daily browsing limits with real-time alerts
  • ✓ Browser Usage Dashboard card with configurable appearance controls
Current Release

v2.1.0 – Hardening, RAM Saver & CWS Compliance

October 2026

Major performance and Chrome Web Store compliance milestone with memory optimization, hardened security screening, and aesthetic wallpapers.

  • ✓ RAM Saver memory optimizer (chrome.tabs.discard with pinned tab safety)
  • ✓ Multi-tier sensitive field screening for optional Draft Recovery
  • ✓ 40 curated wallpapers with dynamic real-time atmospheric canvas effects
  • ✓ Zero broad host permissions (scoped top-level content scripts only)
  • ✓ Full asset provenance documentation in LICENSES.md and ATTRIBUTION.md
Planned

v2.2.0 – Smart Workspace Innovations

Q1 2027

Focus tools and workspace grouping designed to optimize tab management while preserving local-first privacy.

  • • Tab Group Auto-Organizer: Optional grouping of open tabs by workspace or domain using Chrome Tab Groups API.
  • • Local Theme Presets: Custom user wallpaper uploads with client-side compression and offline gradient styling.
